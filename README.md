# Mini Compiler - Person 2 (Front-End & Semantic Analysis)

This repository contains the front-end structural and semantic analysis components for a custom C++ Mini Compiler. It is responsible for parsing a lexical token stream into an Abstract Syntax Tree (AST) and performing rigorous semantic validation before passing it to the Intermediate Representation (IR) generator.

## Architecture

This project is divided into modular compiler phases. The components implemented in this section include:

### 1. Abstract Syntax Tree (AST)
Located in `src/ast/`
- Defines the hierarchical structure of the parsed source code.
- Employs the **Visitor Pattern** (`ASTVisitor`) to strictly decouple the tree structure from the operations performed on it (such as semantic analysis and IR generation).
- **Supported Nodes:** `BinaryExpression`, `LiteralExpression`, `VariableExpression`, `AssignmentStatement`, `IfStatement`, `WhileStatement`, `BlockStatement`, `VariableDeclaration`.

### 2. Parser
Located in `src/parser/`
- A hand-written **Recursive Descent Parser**.
- Consumes a stream of `Token` objects generated by the Lexer.
- Enforces syntax and grammar rules to cleanly construct the AST.

### 3. Semantic Analyzer & Symbol Table
Located in `src/semantic/`
- Traverses the fully constructed AST to enforce language logic rules.
- **Symbol Table:** Manages variable scopes (handling nested blocks), tracks variable types, and monitors initialization states.
- **Validations:** Automatically catches usage of undeclared variables, uninitialized variables, and variable redeclarations within the same scope.

## Documentation
For detailed information on the exact AST structure—specifically designed to be consumed by the Intermediate Representation (IR) Generator (Person 3)—please refer to the [AST Specification](docs/ast-spec.md).

## Building and Testing
A `CMakeLists.txt` is provided to easily compile the front-end components.
A basic integration test is available in `tests/integration/test_parser_semantic.cpp`. It manually mocks a token stream and feeds it through the Parser and Semantic Analyzer to verify correctness without requiring the physical Lexer module.
