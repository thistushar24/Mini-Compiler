# AST Specification

This document defines the Abstract Syntax Tree (AST) generated by the Parser and consumed by the Intermediate Representation (IR) Generator (Person 3).

## AST Structure
All nodes in the AST derive from `ast::ASTNode`, which supports the Visitor pattern via `void accept(ASTVisitor& visitor)`.

There are two main branches of nodes:
- `ast::Expression`
- `ast::Statement`

### Expressions
* **`BinaryExpression`**: Represents arithmetic and logical operations (`left op right`).
  * `left`: `Expression`
  * `op`: `lexer::TokenType` (e.g., `PLUS`, `MINUS`, `EQUAL`)
  * `right`: `Expression`
* **`LiteralExpression`**: Represents hardcoded values (e.g., integers).
  * `value`: `std::string`
* **`VariableExpression`**: Represents a variable usage.
  * `name`: `std::string`

### Statements
* **`VariableDeclaration`**: E.g., `int x = 10;`
  * `typeName`: `std::string`
  * `variableName`: `std::string`
  * `initializer`: `Expression` (Optional)
* **`AssignmentStatement`**: E.g., `x = 20;`
  * `variableName`: `std::string`
  * `value`: `Expression`
* **`IfStatement`**: E.g., `if (x < 10) { ... } else { ... }`
  * `condition`: `Expression`
  * `thenBranch`: `Statement`
  * `elseBranch`: `Statement` (Optional)
* **`WhileStatement`**: E.g., `while (x > 0) { ... }`
  * `condition`: `Expression`
  * `body`: `Statement`
* **`BlockStatement`**: A collection of statements wrapped in `{ ... }`.
  * `statements`: `std::vector<std::unique_ptr<Statement>>`

## Consuming the AST (For Person 3)
To convert this AST into IR, you should inherit from `ast::ASTVisitor` and implement the `visit` methods for each node type.
